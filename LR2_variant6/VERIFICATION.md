# Проверка подготовленного комплекта

Что проверено в текущей среде:

- все три C-файла прошивки успешно проходят компиляцию во фронтенде Clang 17 для `riscv32` (`rv32im`, `ilp32`) с `-ffreestanding -Wall -Wextra`;
- отдельная тестовая линковка подтвердила отсутствие зависимостей от libc (`memcpy` и т.п. не требуется);
- синтаксис всех shell-скриптов проверен командой `bash -n`;
- ожидаемый результат Quick Sort независимо пересчитан: `-11, -4, -2, 0, 1, 3, 5, 6, 8, 9, 12, 14, 17, 19, 21, 23, 27, 31, 35, 42`;
- адреса третьего slave и порядок сигналов в конкатенациях `wbxbar` согласованы: младший элемент — `wb_ram_ip`, затем GPIO, затем boot RAM.

Что **не удалось фактически запустить в этой среде**:

- полный RISC-V GNU toolchain из методички здесь не установлен;
- Verilator/Icarus здесь не установлен;
- Quartus и физическая DE10-Lite недоступны.

Поэтому перед сдачей нужно выполнить на вашей Ubuntu/WSL:

```bash
./run_quicksort.sh
./run_wb_ram_test.sh
./find_max_array.sh
```

и затем аппаратную проверку задания 2 в Quartus по `README_LR2.md`.
